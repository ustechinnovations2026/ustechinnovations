Quimiometría y calibraciones

caliX Suite de calibración

caliX es el completo generador de calibración y espacio de trabajo de modelado de USTECH. Diseñado para químicos e ingenieros de procesos, le permite limpiar curvas espectrales, ejecutar regresiones quimiométricas (PLS, análisis de componentes principales) y compilar calibraciones basadas en aprendizaje profundo para exportar inmediatamente a ProChem.

  • Algoritmos PLS, PCA, ANN, SVM (máquinas vectoriales de soporte)
  • Preprocesamiento SNV, MSC, 1.ª y 2.ª derivadas, Savitzky-Golay
  • Importación de datos Formatos de archivo CSV, JCAMP-DX, NeoSpectra/MasterLine
  • Licencias Suscripción anual de asientos con opciones fuera de línea

Industria 4.0 IoT y automatización

ProChem Smart Suite

Una plataforma de software de IoT industrial independiente diseñada para digitalizar la producción. ProChem coordina múltiples espectrómetros, ejecuta análisis predictivos basados ​​en la nube en tiempo real e integra datos de composición bidireccional directamente con la automatización de PLC de fábrica, silos y sistemas ERP empresariales.

  • Protocolos admitidos OPC UA, Modbus TCP, Profinet, API REST
  • Gestión de datos Replicación segura en la nube de AWS/Azure, caché perimetral de SQLite
  • Inteligencia predictiva Detección de valores atípicos, previsión de desgaste de halógenos
  • Compatibilidad del sistema operativo Windows 10/11, Ubuntu Linux (arquitecturas integradas)
