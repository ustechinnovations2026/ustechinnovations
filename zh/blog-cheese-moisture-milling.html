切达干酪加工中的水分和盐分监测

为什么在破碎与加盐工序设定的盐水比决定切达干酪的成熟，水分和氯化物如何用 ISO | IDF 参考方法测定，以及经同行评审的近红外研究对近线和在线测定这些指标有何揭示。

为什么破碎与加盐决定成熟的走向

切达干酪是一种干盐法干酪：切达化之后，凝块被破碎，在达到所需酸度时，将盐拌入破碎后的凝块，然后入模和压榨，这在切达干酪 Codex 标准关于生产方法的附录中有所描述 [1]。Guinee 的综述阐述了盐如何抑制腐败菌和病原菌的生长，并改变干酪的组成、微生物与酶的活性以及成熟过程中的生物化学变化；由于影响盐吸收和分布的因素众多，精确控制加盐对于质量稳定至关重要 [2]。对于乳品厂而言，加盐输送带是调整一批凝块盐与水分平衡的最后一个环节。

盐水比：关键参数

干酪生产者所使用的参数是盐水比（S/M），即以水分相的百分比表示的盐含量，发酵剂细菌和成熟酶正是在这一水相中发挥作用。Rulikowska 等将切达干酪的加盐量在 0.50 % 至 3.00 %（w/w）之间变化：较低的盐量使 pH 降低、水分活度升高、发酵剂和非发酵剂乳酸菌的生长增加，并增强了蛋白水解，对风味和质地产生不利影响 [3]。Upreti 等在 48 周内比较了 S/M 为 4.8 % 和 6.4 % 的切达干酪，发现低 S/M 干酪的蛋白水解更多、非发酵剂菌数更高 [4]。其姊妹论文表明加盐率如何直接决定 S/M：在 pH 5.4 时以凝块重量的 2.25 % 或 3.5 % 对破碎凝块加盐，S/M 分别为 4.77 % 和 6.68 % [5]。

水分还有法规上限。切达干酪 Codex 标准规定干物质中乳脂的参考水平为 48 % 至 60 %，对于该范围内的干酪，最低干物质为 61 %，相当于最高水分 39 % [1]。

参考方法及其时间成本

干酪中的水分以总固形物的形式，按重量法烘箱干燥参考方法 ISO 5534 | IDF 4 测定 [6]。盐以氯化物的形式，按 ISO 5943 | IDF 88 用电位滴定法测定，适用于氯离子含量超过 0.2 % 的干酪 [7]。两者都是实验室程序；等到结果出来时，产生该样品的凝块通常已经压榨完毕。它们仍是所有规格和定标的基础，但无法在一批凝块还在加盐输送带上时对其进行调控。

干酪的近红外研究显示了什么

近红外（NIR）光谱用于测定切达干酪水分已有数十年。Wehling 和 Pierce 使用三波长滤光片仪器，在 47 个验证样品上相对于烘箱法获得 r² 0.92 和 0.38 % 的性能标准误差（SEP）[8]。样品温度对光谱有显著影响，因此样品须平衡至统一温度，且成熟也可能改变干酪的 NIR 特征 [8]。在后来的一项比较中，对磨碎样品的一阶导数反射光谱进行 PLS 回归，水分 SEP 为 0.335 %，而在完整干酪块上使用光纤探头的可靠性较差 [9]。Margolies 和 Barbano 报告，四家干酪厂的 NIR 仪器在 36 个切达干酪验证样品上，水分的 SEP 为 0.30，脂肪为 0.45 [10]。

盐是较难的参数。在 64 个无机盐含量为 2.0 % 至 4.7 %（w/w）的再制干酪样品中，Blazquez 等最佳的水分和脂肪模型采用了散射校正和二阶导数，但发现盐的预测准确度较低 [11]。在 Margolies 和 Barbano 研究的切达干酪厂中，盐是用库仑法而非 NIR 测定的；在平均盐含量为 1.8 % 时，对溶解干酪采用的中红外透射法 SEP 达到 0.036，而库仑法为 0.139 [10]。实际意义在于：干酪的 NIR 水分测定已相当成熟，NIR 盐定标必须在本厂自己的凝块上验证，而由两项测量计算出的 S/M 值同时带有两者的误差。

从样品杯到加盐输送带

Solberg 等在一种高达类干酪的大规模生产中采用在线 NIR 取代实验室抽样：连续信号给出了更精确的批次估计，并揭示了抽样无法发现的过程波动来源 [13]。以下三项做法可使此类安装站得住脚：

  • 按凝块的实际呈现状态进行定标。已发表的切达干酪定标使用的是磨碎并经温度平衡的干酪，而在完整干酪块上的探头读数可靠性较差 [8][9]；针对处于输送带温度的松散破碎凝块的模型，必须用这种物料建立。
  • 将定标锚定于参考方法。NIR 值的好坏取决于其回归所依据的 ISO 5534 和 ISO 5943 结果 [6][7]，验证应遵循 ISO 21543 | IDF 201 关于乳制品 NIR 应用的指南 [12]。
  • 将水分值用作控制输入。由于在凝块水分一定时加盐率决定 S/M [5]，在加盐前获取读数即可逐批调整加盐量。

USTECH 的做法

对于输送带上的凝块，USTECH 在输送带上方安装 ProLine17EC 在线 NIR 分析仪；其定标在 caliX 中建立，使用上述研究中采用的散射校正、导数和 PLS 工具 [9][11]，ProChem 将读数传送至工厂 PLC，用于加盐设定值控制。在某一工厂的凝块上能否可靠预测盐分，进而预测 S/M，须通过使用您自己样品和参考分析的可行性研究来确定。
