化学计量学与校准模型

caliX 校准套件

caliX 是 USTECH 综合的校准模型构建器和建模工作区。专为化学家和工艺工程师打造，它允许您清理光谱曲线，运行化学计量学回归（PLS，主成分分析），并编译基于深度学习的校准模型以便立即导出至 ProChem。

  • 算法 PLS, PCA, ANN, SVM (支持向量机)
  • 预处理 SNV, MSC, 一阶及二阶导数, Savitzky-Golay
  • 数据导入 CSV, JCAMP-DX, NeoSpectra/MasterLine 文件格式
  • 许可 年度席位订阅，提供离线选项

工业 4.0 物联网与自动化

ProChem 智能套件

一个独立设计的工业物联网软件平台，用于数字化生产。ProChem 协调多台光谱仪，执行基于云的实时预测性分析，并将双向的成分数据直接与工厂 PLC 自动化、料仓以及企业 ERP 系统集成。

  • 支持的协议 OPC UA, Modbus TCP, PROFINET, REST APIs
  • 数据管理 安全的 AWS / Azure 云复制，SQLite 边缘缓存
  • 预测性智能 异常样本检测，卤素灯磨损预测
  • 操作系统兼容性 Windows 10/11, Ubuntu Linux (嵌入式架构)
